## 🌱 About

હું અન્નદાતા એ ગુજરાતના ખેડૂતો માટે બનાવવામાં આવેલ AI આધારિત સ્માર્ટ એગ્રીકલ્ચર પ્લેટફોર્મ છે.

અમારું ધ્યેય ખેડૂતોને AI દ્વારા વધુ સ્માર્ટ અને વધુ નફાકારક ખેતી તરફ લઈ જવાનું છે.
